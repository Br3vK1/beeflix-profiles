# BeeFlix Profiles 1.0.0 Preview

This preview introduces achievement-linked profile rewards, equippable member titles, identity API support, and optional identity badges/profile links on Jellyfin Enhanced community review cards.

- Target platform: Jellyfin 12 (ABI 12.0.0.0)
- Package: BeeFlixProfiles-jellyfin12.zip
- Status: prerelease; live Jellyfin testing required
- Upgrade safety: back up the existing BeeFlix Profiles DLL and plugin configuration before installing.
